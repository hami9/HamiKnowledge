## Concurrent Budget Enforcement Results

- **Ledger-level concurrency:** 20 concurrent worker threads attempted to reserve `$0.001` each against a `$0.005` workspace budget. Exactly 5 reservations succeeded, and exactly 15 were rejected with `BudgetExhaustedError`. Zero unreserved calls occurred, and remaining available funds reconciled without negative drift.
- **HTTP endpoint concurrency:** 20 parallel requests to `POST /v1/workspaces/{workspace_id}/query` against a `$0.001` ceiling budget resulted in exactly 1 HTTP 200 response and exactly 19 HTTP 402 Payment Required responses.

## Bounded Read-Only Agent Verification

The bounded agent implementation (`agent/bounded_agent.py`) satisfies all roadmap contracts:
1. **Permitted tools:** Exactly `search_documents` and `get_document_excerpt`.
2. **Server-side authorization:** Both tools enforce `workspace_id` and document ACLs on the server before querying indices or returning excerpt text.
3. **Hard ceilings:** Maximum 3 tool calls, 20-second request deadline, and per-request cost reservation.
4. **Untrusted content barrier:** Retrieved documents are treated as untrusted text data. Embedded directives (such as shell commands or cross-workspace extraction) cannot alter agent permissions or trigger external tools.
